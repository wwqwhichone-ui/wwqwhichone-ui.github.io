# Weiqi Wang — Portfolio

Source of <https://wwqwhichone-ui.github.io>, built with [Astro](https://astro.build) and deployed to GitHub Pages by
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) on every push to `main`.

```bash
npm ci
npm run dev      # http://localhost:4321
npm run verify   # astro check + vitest + build
```

Personal details live in `src/data/profile.ts`; projects in `src/data/projects.ts`.
